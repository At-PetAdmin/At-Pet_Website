## 准备好素材

一个自定义桌宠通常包含：

```text
my-pet/
  pet.json
  spritesheet.png
```

`pet.json` 定义精灵表文件名、帧尺寸与各状态的动画。精灵表包含连续的动画帧；具体字段见 [动画与 pet.json](../pet-config/)。

## 导入配置与精灵表

从桌宠右键菜单或系统托盘菜单选择 **导入配置与精灵表…**，分别选择 JSON 配置和图片。

At-Pet 会将两者复制到新的宠物库条目中，并重写配置里的精灵图文件名。如果名称重复，会添加数字后缀。

如果已经准备了包含配置及全部引用资源的完整文件夹，也可使用 **导入宠物文件夹…**。

## 预览、切换与删除

在设置中的桌宠库与预览页面选择桌宠。导入的桌宠可以预览 12 秒，再决定是否切换到主位置。

你也可以在宠物库中删除不再使用的条目。保留一份原始素材，方便之后重新导入。

## 同时召唤多只桌宠

桌宠右键菜单第一层的 **全员上班** 会打开宠物库中所有已导入的有效桌宠，并在屏幕上排列。托盘菜单也提供“召唤全部桌宠”。

重复召唤会重新创建这组桌宠，不会无限累积重复实例。

## 修改后立即生效

At-Pet 会监视已导入的 `pet.json`、精灵表和所在文件夹。修改配置或图片后，无需重启应用。

使用宠物库中的 **编辑 pet.json…**，可以在文本编辑器中修改所选桌宠的配置。应用会在保存前校验 JSON，保存成功后立即热加载。

## 文件保存在哪里

Windows 上的宠物库位置：

```text
%APPDATA%\Ni-ShuWu\At-Pet\pets
```

独立语录和全局语录另行保存，不需要放进桌宠文件夹。为某只桌宠定制台词时，继续阅读 [语录包](../quotes/)。
