## 基本操作

| 操作 | 效果 |
| --- | --- |
| 单击 | 戳一戳，显示随机问候或语录 |
| 双击 | 输入想让桌宠说的话 |
| 拖动 | 将桌宠移到屏幕内的其他位置 |
| 右键 | 打开桌宠菜单、设置与宠物库等控制入口 |
| 系统托盘 | 显示、隐藏、导入或召唤桌宠 |

桌宠窗口透明、无边框且始终置顶。拖动、甩出和重力都会将它保持在屏幕范围内。

## 自由走动与重力

桌宠默认会在屏幕内上下左右自由走动。可以在右键菜单切换该行为，选择会被记住。

启用重力后，桌宠被拖起再放开会落下，甩出时会保留拖动的惯性。它会在屏幕边缘反弹，落到底部时弹起，并逐渐降低弹跳高度直到静止。开启重力时，自主走动限制在地面。

在常规设置中调整“重力系数”，控制下落速度；默认值为 `1.00`。

## 坐在窗口边上

将桌宠拖到其他带边框窗口的标题栏，例如 VS Code 或资源管理器。它会走向边缘，进入挂件模式。

挂载后，桌宠会随宿主窗口的移动与缩放一起移动。它可以自行沿边框下滑，也可以从右键菜单选择“沿窗口边框下滑”。拖走桌宠即可离开宿主窗口。

## 看向你的鼠标

右键菜单中的“看向鼠标指针”，或常规设置中的“眼睛跟随鼠标指针（Windows）”，可以让桌宠的视线跟随指针。

这项功能只改变视线，不会检测 Copilot 或其他 Agent 的会话状态。Agent 状态需要 [单独接入](../agents/)。

## 留一点专注空间

在常规设置启用“全屏应用时自动免打扰（缩小并贴到屏幕边缘）”。前台运行全屏游戏或编辑器时，所有桌宠会缩成贴边的小气泡。

从托盘重新召唤，或取消“免打扰”，可以回到原来的位置。托盘菜单也支持手动切换。

## 全员上班

右键桌宠，在第一层菜单选择“全员上班”，即可同时打开并排列库中所有已导入的有效桌宠。重复点击会重新召集，不会持续添加重复实例。

如果还没有导入其他桌宠，先看 [宠物库与导入](../pet-library/)。
